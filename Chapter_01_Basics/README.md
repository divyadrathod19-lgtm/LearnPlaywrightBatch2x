# Chapter 1: Basics

## Overview
Introduction to JavaScript and verification of your development setup.

## Learning Objectives
- Verify JavaScript environment is correctly set up
- Understand basic JavaScript concepts
- Learn how to run JavaScript files

## Files in This Chapter

### 01_Basics.js
Basic JavaScript introduction covering fundamental concepts and syntax.

### 02_JS.js
JavaScript fundamentals and core concepts.

### 03_JS_verify_setup.js
Script to verify that your JavaScript environment is properly configured.

## How to Run

1. Open a terminal in this directory
2. Run any file with Node.js:
   ```bash
   node 01_Basics.js
   node 02_JS.js
   node 03_JS_verify_setup.js
   ```

## Prerequisites
- Node.js installed on your system
- A code editor (VS Code recommended)

## Expected Outcomes
After completing this chapter, you should be able to:
- Verify your JavaScript setup is working
- Understand basic JavaScript syntax and concepts
- Run and modify JavaScript files

Proceed to **Chapter 4: JavaScript Concepts** for deeper understanding of variables, functions, and scope.
