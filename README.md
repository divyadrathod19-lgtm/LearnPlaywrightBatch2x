# Learn Playwright Batch 2x

A comprehensive learning repository for JavaScript fundamentals and Playwright automation testing concepts.

## Overview

This repository contains structured learning materials organized into chapters covering:
- JavaScript basics and setup verification
- JavaScript core concepts (variables, functions, scope, hosting)
- Java basics
- Advanced testing with Playwright

## Repository Structure

```
LearnPlaywrightBatch2x/
├── Chapter_01_Basics/                  - Introduction to JavaScript and setup verification
├── Chapter_02_java_Basic 2/             - Java fundamentals
├── Chapter_04_Javascript_concepts/      - Advanced JavaScript topics (variables, functions, scope, hoisting)
└── Chapter_10_Loops/                    - Loop constructs and iteration exercises
```

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/divyadrathod19-lgtm/LearnPlaywrightBatch2x.git
cd LearnPlaywrightBatch2x
```

2. Navigate to a chapter directory:
```bash
cd Chapter_04_Javascript_concepts
```

3. Run a JavaScript file:
```bash
node filename.js
```

## Learning Path

1. Start with **Chapter 1: Basics** to verify your setup
2. Progress to **Chapter 4: JavaScript Concepts** for detailed explanations
3. Explore **Chapter 2: Java Basics** for Java fundamentals

## Requirements

- Node.js installed (for running JavaScript files)
- Java Development Kit (for Java files)
- A code editor (VS Code recommended)
